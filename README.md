# Micro-E-commerce-Profit-Inventory-Optimizer-MEPIO-
MEPIO is aDesktop Application designed specifically for micro-entrepreneurs operating on platforms.  The system integrates financial analytics with inventory management, automating net profit calculations and predicting stock depletion. The system empowers small sellers to make data-driven business decisions.

【MEPIO System Demo and Operation Instructions】

1. System Environment: This software is fully packaged as a standalone Windows version, requiring no Python environment installation.

2. First Run/Demo Steps:

- Step 1: Double-click to run `Init_Demo_Data.exe` in the 【MEPIO_System_Application】 folder.

(The system will automatically initialize the local SQLite database and inject 25 simulated e-commerce order and inventory demo data).

- Step 2: Double-click to run `MEPIO_System.exe` in the same folder to directly enter the system and view the complete charts and dashboard demo.

3. Notes: To clear the demo data and restore the clean version, simply delete the `mepio_system.db` file in the folder.
